## Project Structure

Each project should have its own markdown file with:

- **Overview** - What is this project?
- **Goals** - What are we trying to achieve?
- **Status** - Current state and progress
- **Technical Details** - Architecture, stack, dependencies
- **Resources** - Links to repos, designs, related docs
- **Timeline** - Key milestones and deadlines

## Template

```markdown
# Project Name

**Status:** Planning | In Progress | On Hold | Completed  
**Owner:** Name  
**Started:** YYYY-MM-DD  
**Repository:** [link]

## Overview

Brief description of what this project is...

## Goals

- Goal 1
- Goal 2

## Technical Details

Stack, architecture, key decisions...

## Resources

- [GitHub Repo](url)
- [Design Doc](url)
- Related: [Other Project](../other-project.md)

## Progress

### Completed
- [x] Task 1

### In Progress
- [ ] Task 2

### Planned
- [ ] Task 3
```
